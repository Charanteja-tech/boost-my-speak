# SpeakUp AI Coach

Build a polished AI web application called "SpeakUp AI – Presentation Coach".

The app helps students improve speeches, presentations and public speaking.

DESIGN:

- Premium modern AI SaaS design

- Dark theme

- Clean professional typography

- Beautiful dashboard

- Subtle animations

- Responsive

- Avoid generic template appearance

SpeakUp AI logo

Coach | History | Tips

"Get instant feedback on your presentation before you step on stage."

"Paste your speech here..."

Add sample speech button:

"Try an example"

"Analyze Presentation"
